# 调研依据与设计启示

检索日期：2026-09-20。优先采用官方法规、官方技术文档与头部研究机构材料。

## 1. 为什么值得做

麦肯锡指出，生成式 AI 可把过去需要数月的内容设计、洞察和客户定向流程缩短到数周甚至数天，并支持规模化个性化与自动测试。这里的启示不是套用外部 ROI，而是把营销内容从“单件手工制作”改造为可编排的生产系统。  
来源：[How generative AI can boost consumer marketing](https://www.mckinsey.com/capabilities/growth-marketing-and-sales/our-insights/how-generative-ai-can-boost-consumer-marketing)

Adobe 对企业内容生产的产品定义也强调：从简报到最终资产的重复步骤可以被工作流自动化，品牌规则和人工控制应与生成能力同时存在。这直接支持本方案采用“实时生成 + Agent 编排 + 人工确认”，而不是只提供自由提示词。  
来源：[Production Workflows for Content Creation](https://business.adobe.com/products/firefly-business/firefly-creative-production/production-workflows.html)

## 2. 技术可行性

多模态模型可以同时接收文本和图片，适合分析外观、可见结构、颜色和文字；但视觉识别结果不能替代正式规格资料。因此系统把图片识别作为候选线索，把产品资料作为技术主张的证据源。  
来源：[OpenAI API — Create a model response](https://developers.openai.com/api/reference/cli/resources/responses/methods/create)

Comfy API v2 的公开规范包含资产上传、工作流提交、任务状态和结果获取，说明图像工作流可以被应用层标准化调用并支持自托管/云端切换。它适合作为后续视觉生成适配器之一，而不应成为唯一依赖。  
来源：[Comfy API v2 OpenAPI specification](https://github.com/Comfy-Org/docs/blob/main/openapi-v2.yaml)

Cloudflare Workers AI 在免费计划中提供每日 10,000 Neurons 的免费分配，额度用尽后免费计划请求失败而不是产生超额费用；其模型目录同时提供视觉理解、参考图编辑和代码生成模型，适合本次不绑定信用卡的演示。
来源：[Workers AI Pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)、[Workers AI Models](https://developers.cloudflare.com/workers-ai/models/)

Moondream 3.1 是 Cloudflare 托管的快速视觉语言模型，可用于产品观察和生成角色的产品血缘复核；FLUX.2 Klein 4B 支持最多四张输入参考图，可用产品图生成角色，再用产品与定妆图共同约束动作主视觉。
来源：[Moondream 3.1](https://developers.cloudflare.com/workers-ai/models/moondream3.1-9B-A2B/)、[FLUX.2 Klein 4B](https://developers.cloudflare.com/changelog/post/2026-01-15-flux-2-klein-4b-workers-ai/)

## 3. 合规约束必须内建

《中华人民共和国广告法》要求广告真实、合法，不得含有虚假或引人误解内容；涉及商品性能、功能、用途、质量等信息时应准确、清楚、明白。由此得出产品规则：每条对外卖点必须绑定来源，模型推断不能自动升级为事实。  
来源：[中华人民共和国广告法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)

《生成式人工智能服务管理暂行办法》明确要求尊重知识产权、商业道德和商业秘密。由此得出 IP 规则：热门/经典角色只能作为方向检索；未获得明确授权时，系统应转为原创角色，不生成高度近似形象。  
来源：[生成式人工智能服务管理暂行办法](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202401/t20240109_493171.html)

《人工智能生成合成内容标识办法》自 2025 年 9 月 1 日施行，覆盖文本、图片、音频、视频和虚拟场景，并规定显式与隐式标识要求。由此得出导出规则：交付包需保留可见声明、元数据标记和版本日志能力。  
来源：[人工智能生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)

## 4. 本方案采用的审慎口径

- 不引用外部厂商的收益比例作为本项目已实现收益。
- 不根据图片猜测型号、内部技术或功效。
- 不把“像某知名角色”当作安全的原创方案。
- 不在不了解公司数据制度时假设外部 API 可处理未上市产品资料。
- 用 5–10 个真实内部任务建立自己的效率基线，再形成路演数据。

## 5. 下一轮调研缺口

1. 公司内部从新品卖点到互动营销的真实角色、周期、返工次数与成本。
2. 比赛评分细则对创新性、商业性、技术性与完成度的权重。
3. 公司模型网关支持的视觉输入、图片生成、文件解析和审计能力。
4. “牛来”角色的权属、授权范围、品牌禁用场景。
5. 内部产品图、规格书与未上市信息的数据分类及出域规则。
