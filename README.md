# 卖点有戏｜AI 互动营销 OPC

这是基于“牛来桌宠/0907发展建议.txt”形成的第一阶段项目包。目标不是再做一个普通海报生成器，而是把家电产品图与经过确认的产品卖点，转化成可体验、可传播、可复用的互动营销方案。

## 本阶段已交付

- `01_初步方案.md`：竞赛口径的一人公司完整方案。
- `02_Agent矩阵与全流程.md`：AI Agent 角色、协同、人工闸门和技术实现。
- `03_MVP与落地路线图.md`：可执行范围、排期、指标和迁移方案。
- `04_待确认事项.md`：需要项目负责人选择的关键分叉，含推荐项。
- `05_路演演示脚本.md`：3 分钟演示与评委问答。
- `research/调研依据.md`：市场、技术与合规依据。
- `assets/概念主视觉.png`：第一版概念主视觉。
- `assets/概念主视觉_生成说明.md`：图像生成模式与最终提示词。
- `dist/index.html`：可直接打开的交互原型，也是后续 GitHub Pages 演示入口。

## 立即体验

- Vercel 完整版：https://maidian-youxi.vercel.app
- GitHub 仓库：https://github.com/tomo-opt/maidian-youxi

依次体验“导入产品 → AI真实分析 → 确认卖点 → 选择玩法 → 实时生图与生成HTML → 沙箱试玩/下载”。GitHub Pages 会自动连接上方 Vercel 生成服务，不需要评委配置密钥。

## 一句话定义

**一人输入一组产品图和可信卖点，AI Agent 团队在一次工作流里交付“卖点策略 + 互动玩法 + 视觉方向 + 可发布样稿”。**

## 当前推荐结论

- OPC 名称：卖点有戏·AI 互动营销工作室
- 产品名：卖点有戏（英文工作名：HookPlay）
- 首个样板：冰箱 × 原创牛来角色；同时支持洗衣机、空调和任意家电上传
- 首期用户：公司内部产品经理、营销经理、区域内容团队
- MVP 原则：不依赖预制互动模板，AI根据每次输入实时生成原创视觉与单文件互动 HTML

## 当前技术链路

- Cloudflare Moondream：实时读取产品图中的可见外观、结构与场景。
- Cloudflare Llama 策略模型：把视觉观察整理为可信卖点与三套互动创意。
- Cloudflare FLUX：实时生成原创角色/场景素材。
- Cloudflare Qwen MoE：从本次简报实时编写单文件互动 HTML。
- 浏览器沙箱：生成的 HTML 禁止联网，在隔离环境中试玩，并可下载为独立文件。
- GitHub Pages 与 Vercel 只负责免费静态托管，AI 调用走 Workers AI 每日免费额度；无需信用卡或永久 API Key。

## 边界

- 原“牛来桌宠”目录未被修改、移动或删除。
- 概念主视觉不含现成 IP、品牌标识和功效承诺。
- 所有效率与业务指标均被标注为待验证目标，不当作既成事实。
